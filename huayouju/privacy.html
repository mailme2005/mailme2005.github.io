适用范围

本政策适用于「花有据 / Huayouju」iPhone 应用及本支持网站。开发与运营者为 Guan Jie Tan，发布名称为 Little Everyday Apps。隐私联系邮箱：tripzy053@gmail.com。

当前版本为 0.7.0 私人 TestFlight 测试版，已提供云端识别及沙盒识别包购买。正式 App Store 付费服务尚未开放，测试余额与正式余额分开。以下说明对应当前实现。

设备上的账目与照片

收据照片、识别文字、商家、日期、金额、币种、分类、支付及核对状态、识别提示，以及语言和使用偏好保存在本机。本机识别使用设备上的文字识别功能；未启用 Claude 时，收据不会为识别而上传到我们的云端。

应用还保存未完成处理的状态及最多 5 份近期账本快照，用于防止重复处理和恢复损坏账本。账目文件受 iOS 文件保护；系统备份可能包含本机数据，取决于你的 Apple 设置。我们不提供整本账目或原图的云端同步与远程恢复。

可选 Claude 云端识别

启用前，应用会征求同意。启用后，新拍摄或导入的收据会将压缩图片及本机识别出的文字，通过 Google Cloud 托管的花有据服务发送至 Anthropic 的 Claude API，以整理消费资料。图片或文字可能包含姓名、地址、商家、消费明细、金额、会员号码或付款信息。应用在重新编码上传图片时不复制原照片的元数据，但图片画面或文字中可见的信息仍会上传。

可以在「设置」关闭「Claude 收据识别」，停止之后的云端提交；已经发送的请求无法撤回。关闭后仍可使用本机识别和手动录入。我们不连接银行，也不主动索取银行卡号，但你选择上传的收据本身可能包含此类信息。

云端处理及保留期限

花有据服务处理上传图片和文字，不将原图或原始 OCR 文字持久保存到请求账本。提取的收据结果会临时保存，供中断后取回：最多可取回 24 小时，手机确认保存后提前删除。到期后不再返回结果，后台清理随后完成；这不是永久云备份。

防止重复调用的请求编号、内容摘要、状态、时间、模型及费用/用量记录会继续保留。识别包版本还将请求与去标识化账号关联，记录次数预留和结算，以处理余额及争议；这些记录没有与结果相同的 24 小时到期机制。

Anthropic 的标准 API 政策规定输入及输出通常在 30 天内删除，安全执行、法律义务、受控模型要求或另行协议等情况可能延长保留。我们没有宣称零保留协议。Anthropic 默认不使用商业 API 输入和输出训练模型；明确反馈或选择共享等情形可能例外。参见 API 保留政策及训练政策。

App Store 身份、余额与购买

应用核对余额和处理购买时，会将 Apple 签发的应用及购买凭证发送到花有据服务进行验证。无需另建花有据账号，也不向我们提供 Apple 密码。我们不为此索取姓名或邮箱；凭证包含应用、账号关联、环境及交易信息。

服务器使用应用交易标识生成去标识化账号引用，并保存免费与付费余额、预留次数、应用账号令牌、产品及交易标识、验证时间和退款状态。这些记录用于一次性发放试用、交付购买、防止重复到账、同步余额及处理退款。付款由 Apple 处理，我们不会从 Apple 收到付款银行卡号。

免费及购买次数不过期。余额、试用领取、交易与防重复记录在提供次数、处理退款和争议、防止滥用或履行适用义务所需期间保留；卸载应用不会清除这些服务器记录或再次发放免费次数。

服务商及处理地点

Google Cloud 托管花有据服务及次数账本，当前服务和数据库设于新加坡；Anthropic 处理选择提交的 AI 请求，Apple 提供应用分发及支付服务。服务商也可能依据其政策处理 IP 地址、应用或设备信息、安全事件和运行日志，数据处理可能发生在你所在国家或地区以外。

这些资料用于功能交付、安全及问题排查。花有据没有广告、跨应用追踪或第三方分析 SDK，不出售个人信息。应用不请求通讯录、定位或麦克风权限。

权限、导出与删除

相机仅在你选择拍摄收据时使用，可在 iOS 设置管理权限。导入图片时，通过系统选择器选取你要使用的照片。导出完整备份、CSV 或分享文件时，由你选择存储位置或接收方；完整备份包含原始收据照片和账目，请妥善保管。

可以在应用内删除账目。为支持恢复，删除的账目及相关照片可能仍存在于近期本机快照中，直到快照轮换清理。删除应用及其数据可移除本机文件；iOS 的「卸载 App」会保留数据。导出文件、系统照片、分享内容及设备备份需在各自位置另外管理。

如需查看、更正或删除与云端服务、购买或客服有关的数据，请联系隐私邮箱。当前版本没有应用内云端账号删除按钮。我们可能要求验证相关账号或交易，说明可删除范围，以及为保留已购买次数、处理争议、防止重复试用或依法必须保留的最少记录。不要发送 Apple 密码或完整签名凭证。删除本机账目不会自动向 Apple 申请退款，服务商日志及备份按其机制保留和清理。

客服邮件与本网站

主动发邮件时，我们收到你的邮箱、正文及所选附件，仅用于回复、排查问题和处理请求。客服使用 Gmail；邮件及附件在支持、跟进或适用义务所需期间保留，不再需要后删除。请先遮挡收据中的无关个人资料。

网页由 GitHub Pages 托管，没有添加分析脚本、追踪像素、广告、Cookie 或外部字体。GitHub 会为安全目的记录访客 IP 地址。访问外部链接时适用对应服务商政策。
