@summary 《移动堡垒》可以离线玩，不需要注册账号，没有广告和内购，也不追踪你。你的进度只保存在你的设备上。只有你使用 Game Center 时，成绩和成就才会发给 Apple。

## 我们会收到什么
游戏本身不会把你的任何资料发给我们。只有你主动发邮件联系我们时，我们才会收到你的邮箱地址和你写的内容。
### 玩游戏时
合金、升级、任务进度、勋章、无尽和每日挑战纪录、涂装、主炮选择，以及语言和声音设置，都保存在你的设备上。游戏没有广告，没有内购，不追踪你，不做使用统计，也不会要求使用定位、相机、麦克风、通讯录或照片。
### 使用 Game Center 时
Game Center 是可选的。如果设备登录了 Game Center，游戏会把你的成就、无尽突围最高分和每日挑战用时发给 Apple 的 Game Center，用来显示排行榜和你的 Game Center 资料。我们不会收到你的 Game Center 账户资料。不登录也可以正常玩。

## 谁会帮忙处理
- **Apple**：负责游戏的下载和 Game Center。如果你开了 iCloud 备份，备份由 Apple 按你的设置保管。
- **邮件服务（Gmail）**：只在你发邮件给我们时用到。
- **这个网站**：没有广告，也没有统计脚本。网站托管方 GitHub 可能留下 IP 地址等基本访问记录。
> 它们各自的说明：[Apple 隐私政策](https://www.apple.com/legal/privacy/) · [Google 隐私政策](https://policies.google.com/privacy) · [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

## 资料存在哪里，怎么删除
### 存在哪里
在你的设备上。游戏自己没有云存档；如果你开了设备备份，备份里可能包含游戏进度。我们没有你存档的副本，所以无法替你查看或恢复。
如果存档读不出来，你可以用系统分享把原来的存档导出，或者让游戏先在设备上保留一份再重新开始。导出的那一份只会发到你选的地方，也不保证一定能修复。
### 怎么删除
- 在系统设置里删除游戏，存档、设置和保留的副本会一起删除。如果只是「卸载 App」，数据会保留。
- Game Center 里的成绩和成就由 Apple 保存。你可以在设备设置里退出 Game Center；要删除 Game Center 资料，请通过 Apple 的隐私页面联系 Apple。
- 设备备份里的那一份，请在系统的备份设置里管理。
- 想查看、更正或删除和我们往来的邮件，用原来的邮箱来信告诉我们即可。
